# Excersism SQLite Solutions
Este repositorio documenta las soluciones de los ejercicios de SQLite de Excersism. Su propósito es registrar mi progreso, mejorar la lógica de bases de datos y servir como una fuente de referencia para la aplicación de funciones avanzadas de SQL (CAST, MOD, CTEs, etc.).
